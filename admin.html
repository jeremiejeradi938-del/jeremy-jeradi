Website connection (GitHub)

This dashboard needs a GitHub access token to publish your changes to the live website. This is entered once and saved only in this browser — it is never uploaded anywhere.

To get one: go to github.com/settings/tokens, create a new "Fine-grained token", give it access to only the jeremy-jeradi repository, and under Permissions set Contents: Read and write. Then paste it below.
